# A flooded sea-cave. Pull LEVERS to raise portcullis (switch_door) gates,
# grab the SURFBOARD, then use it to cross the flooded back rooms that gate
# the boss. A TIDE SENTINEL sub-boss guards the surfboard chamber.
# Layout (sx 7-9, sy 10-12):
#  keyroom(7,10) - pool(8,10) - bosskey(9,10)
#  hall(7,11) -- surf(8,11) -- approach(9,11)
