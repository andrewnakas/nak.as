# Hello, world

Hello world welcome to nak.as the personal website of Andrew Nakas, I plan to update this website with things i'm working on and life updates and such. The time is 8;48 pm, i'm in Red Lodge Montana, outside Grizzly Pine Outfitters using their free wifi, Thanks Red Lodge.

I'm in Red Lodge because i'm working up at Summer ski area on the pass, the Beartooth Basin. It's a crazy ski area with double black diomond terrain at 10,000 fete with 2 pomas built in the 80s run off a generator and is only open from memorial day weekend to the middle of June. There is no service and it's really remote, last year they got Starlink, so they finally accept credit cards. It's been so great working there, we just got done two weeks of setup, getting the lifts and ski runs ready, and now we are in operations. I'm carrying medical gear and ski patrolling in needed but, mainly i'm operating the lifts and making the place run. Today we had 6 people total to run the whole mountain.  The cornice gets blown up at the beginning of the year to reduce hazard. Which is crazy because unlike most resorts the avalanche hazards are directly above the lift towers. A couple years back the cornice was blown and it fell down the run and took out a lift tower that took two weeks to dig down to the base and fix. There was a cornice the developed a big crack above inbounds terrain and the team is going up at 6am tomorrow morning to blow it up. Hopefully it won't take out the lift.

I've been vibe coding at night, I've been playing around with building wasm websites that do file utility things, with multimedia. I've made 9 websites so far.
 freebookconvert.com a book conversion website
 pdftoolbench.com a pdf conversion website
audiosaw.com an audio conversion website.
freephotoconvert.com and fixheic.com photo conversion websites
shrinkvideo.com a video conversion website
extract7z.com and unrarit.com extraction and compression websites
exebrowser.com a windows 32 bit exe emulator

All these websites use web assembly to do all the conversions locally in your browser. The idea being is that you don't need an app downloaded to do these conversions, they work on mobile and only use a web server toi deliver a static page, reducing server usage as most websites that have this functionality have a backend server that does the processing. I think im onto something here, and i've been riffing on trying to turn exebrowser to have 64 bit exe file emulation, which is a harder task and i think will only work on chrome browsers. For now i'm playing skifree.exe on my browser.
