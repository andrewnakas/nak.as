# Hello, world

This is the first post on **nak.as**. I built this site to have a single place that's mine — a 3D scan of me, the old Nakas Motivation soundboard, and now a spot to write things down.

## What lives here

- A 3D scan of me, spinning, drag-to-rotate.
- The Nakas Motivation soundboard from 2015, with a little talking-face animation that lip-syncs to whichever clip is playing.
- This blog.

## How posts work

Each post is a markdown file in `posts/` in the [GitHub repo](https://github.com/andrewnakas/nak.as). Add a file, add an entry to `posts/index.json`, push, and Cloudflare rebuilds. No CMS, no database — just text.

More to come.
